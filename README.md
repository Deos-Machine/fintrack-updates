# Фінтрек

Трекер витрат по картці ПриватБанку: сам ловить оплати з push-повідомлень Приват24, розкладає
їх за категоріями банку і попереджає, коли наближаєшся до ліміту. Дані зберігаються лише на
телефоні.

## Встановити

1. Відкрий [останній реліз](https://github.com/Deos-Machine/fintrack-updates/releases/latest) з телефона.
2. Завантаж файл **`fintrack-….apk`**.
3. Відкрий файл і натисни «Встановити». Телефон попросить дозволити встановлення з браузера —
   дозволь. Якщо Google Play Protect попередить про невідомого розробника — «Усе одно встановити».

## Увімкнути автозахоплення

1. У Фінтреку: **Ще → Автозахоплення витрат → Відкрити доступ до сповіщень** і увімкни «Фінтрек».
2. Якщо перемикач неактивний або Android пише про обмежене налаштування — так він захищає
   застосунки не з Play Маркету. На тому ж екрані натисни «Відкрити сторінку застосунку», далі
   **⋮** угорі праворуч → **Дозволити обмежені налаштування**, і повтори крок 1.
3. Переконайся, що в Приват24 увімкнені push-сповіщення про операції за карткою.

Після першої ж оплати карткою на екрані «Автозахоплення витрат» з'явиться сповіщення банку і
позначка, чи стало воно операцією. Якщо ні — кнопка «Поділитися» віддає текст сповіщення, щоб
доучити розбір.

## Оновлення

Нова версія ставиться поверх старої з тієї ж сторінки релізів, дані зберігаються. Сповіщення,
які раніше не розібралися, після оновлення розбираються заново самі.

## Приватність

Без хмари, реклами й акаунтів. Застосунок читає лише сповіщення Привата; сповіщення інших
застосунків не зберігаються навіть сирими.

Перевірити, що файл справжній: SHA-256 APK вказаний в описі релізу.
